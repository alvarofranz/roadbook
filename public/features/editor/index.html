Roadbook editing workflow: Tips & tricks

Clean the GPS track

Simplify (Douglas-Peucker) removes zig-zag from a noisy track while keeping your note anchors; Draw extends the nearest open end and Insert adds a point on a segment. The point tools have one-key shortcuts.

Build notes in order

Road surface → junction vectors in the vignette → context icons (houses, trees, hazards). It keeps notes consistent and fast to read.

Load support images

Insert images of the junctions to help design the roadbook — you can right-click the map to go to Street View and check. Paste an image with Ctrl+V onto a note, or use Upload icon in the palette; roughly square images render best.

Set the road surface first

A note's Road carries forward to the following notes until another note changes it — so set it on the first note and again wherever the surface changes (asphalt → track → off-piste).

Set Waypoint type & radius

Choose the FIA waypoint type (it sets the map badge and, in a rally roadbook, how it's scored) and a validation radius — the Reader's geofence for automatic pass detection.

Junctions & roundabouts

Draw the junction vectors so the exit is unmistakable, and drop the waypoint at the real exit so the Reader's detection radius validates the pass where it should.

CAP & speed

Toggle a Red CAP and pick its type (exit / average / calculated / turning). A declarative speed limit also marks the note a controlled zone.

Save locally or on server

Keep your work two ways: export a self-contained .rdbk file to your device, or — signed in — Save to your profile so it's stored on the server, syncs across devices and stays re-editable.

Export & share

Export to GPX / OpenRally for other devices, or a print-ready PDF; publish a saved roadbook as public (shareable) or keep it private.
