Organising an event

An event — a rally or meet-up, say — can be made of one or more roadbooks prepared by the team that organises it, then gives registered participants controlled access to them. Participation can be free, or scored using the Reader's Competition mode.

The event, step by step

1 Preparation

To create the event, open Event management → New event and set the title, description, start/end dates, an optional logo, and the participant categories (e.g. SUV / modified vehicles / experts).

To build the team, use the Organizers section — search users by name and add co-organisers. The owner (and admins) control the organiser list, the visibility and deletion; co-organisers manage the content and can co-edit the event's roadbooks, with a soft lock keeping it to one editor at a time.

To gather the routes, in the Roadbooks section attach your own roadbooks and set each one's participation mode (Free = follow with no scoring · Roadbook-suite rules = the current scoring). Drafts stay private — only public or ready roadbooks are shown to people.

Getting the organiser role

To create events you need the organiser role — just send us your username. Once we grant it, the Event management entry appears in your account menu (top-right); from there you can create and manage your own events.

Request the organiser role

2 Publish

To make the event visible, turn on Public — it then appears in the public events list with its own presentation page. Participants and organisers also see the event's ready roadbooks there, not only the public ones.

3 Join

To let people in, generate a join code in the Participants section and share it — a signed-in user joins by entering it, which unlocks the event's ready roadbooks. To manage the roster, the participants page lists who joined (searchable) and lets you remove someone.

4 Run

To follow a roadbook, participants open it in the Roadbook Reader — in Trip mode to follow the route, or Competition mode to be scored.

5 Results

To rank the teams, collect the signed result QR that each Competition run produces and load them into the Ranking tool for the final classification.
