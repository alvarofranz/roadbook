Learn to read the terrain, one note at a time.

A roadbook makes each junction part of the ride. Instead of only watching a line on the map, you work with a distance, a tulip diagram and a direction. Use RDBK to prepare an enduro loop, document an adventure-bike trip or build a route for rally navigation practice. Start with familiar tracks and add the details that make each turn recognisable.

Before you set off

Can I use a handlebar remote?

RDBK supports keyboard-style remote inputs with configurable controls. Pair your compatible Bluetooth controller with the device, configure its buttons in your profile and check them before riding. The Reader uses that mapping while navigating. Compatibility depends on the signals your controller sends.

Can I follow a roadbook without mobile data?

Open your roadbook before setting off. A .rdbk file contains its track, notes and symbols, and GPS positioning does not require mobile data. Online maps, downloading shared roadbooks and syncing your account still need a connection.

Browser or native app: which should I use?

Use the web Editor on a large screen to prepare your route. On the trail, the iOS and Android apps add background GPS, so a recording can continue with the screen locked. Use the same .rdbk roadbook across devices.
