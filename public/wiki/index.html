Getting Started

The Getting Started guide takes you through the fundamentals of RDBK.app, including how to register, understand the main tools available, and start recording your first roadbook.

Key topics covered:

  • Setting up an account
  • Understanding the 4 main tools (Recorder, Editor, Reader, Tripmaster)
  • Understanding roadbook workflow
  • Finding help and support

Recorder

The Recorder guide details how to record GPS tracks in the field, from start to finish.

Key topics covered:

  • Starting and stopping recordings
  • Adding waypoints, photos, and audio notes
  • Managing recordings offline
  • Exporting and editing recordings

Editor

The Editor guide explains how to create and refine roadbooks from recorded tracks or from scratch.

Key topics covered:

  • Understanding the map interface
  • Creating and managing notes
  • Adding photos and audio annotations
  • Exporting in various formats
